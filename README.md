# Global Token-Optimization Protocol for Claude Code

A minimal global configuration file (`CLAUDE.md`) for **Claude Code** that enforces strict delta-only code outputs, suppresses conversation re-reading, and eliminates AI filler to save output tokens.

## Quick Install

Run this command in your terminal to create your global config folder and install the rules automatically:

```bash
mkdir -p ~/.claude && curl -fsSL https://raw.githubusercontent.com/honganhtruong1212-source/claude-token-optimizer/main/CLAUDE.md -o ~/.claude/CLAUDE.md
```
