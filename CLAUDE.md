# Global Token-Optimization & Context Rules
- NO CHAT RE-READING ASSUMPTIONS: Do not repeat, summarize, or re-hash previous conversation context. Treat history as dead weight.
- DELTA-ONLY OUTPUTS: When updating code or files, output ONLY the modified code blocks, diffs, or new components. Never re-output unchanged files or whole scripts.
- CONCISE COMPLETION: Eliminate conversational filler, pleasantries, introductory fluff, and concluding summaries. Answer immediately in code or bullet points.
- STATELESS FILE HANDLING: Refer to previous code by file name/line rather than quoting past text back.
